# MamaPal · 产品与开发记录

> 内部页面，无入口，地址 `/doc`。随做随更新，避免细节遗漏。最后更新：2026-10-11。
> 比赛：PayPal AI Hackathon，截止 2026-11-12 下午 2 点（太平洋时间）。仓库 github.com/haodaz/mamapal，线上 mamapal.vercel.app。

## 一句话

Pal cares · Pal cuts · Pal claims（它管 · 它砍 · 它领）。一个月 $400 的妈妈的守护者。不是给妈妈一个 SaaS，是给她一个 Pal：陪她谋划一切，关心她和宝宝。

## 定位决定

- 用户是低收入妈妈，理解力和时间都有限。界面要温暖、说人话；对商品狠，对妈妈温和，不说教。
- 首页不是仪表盘，是 Pal 本人在说话：气泡 + 它递来的卡片。输入框在页面底部。
- 「我」是记录，不是设置。设置折进一张「现状」卡，点编辑才展开。
- 预算分层按马斯洛：先必需（尿布、奶、吃的、健康、护理、衣服），有余力再成长启蒙（玩具、书），再有余力才开心出游。Pal 判定时按这个顺序分钱。
- 月龄按实际月龄，不做矫正月龄（简化，评委不看这么细）。医疗情况写在孩子备注里给 Pal。
- 不用 PayPal 商标做产品名。产品叫 MamaPal，角色叫 Pal。

## 功能点

### Pal cares（它管）
- 档案：称呼、孩子（名字、出生年月、医疗备注）、每天尿布片数、每天奶粉 ml、家里几口、月收入、邮编、州、怀孕/SNAP/Medicaid。存在「我」。
- 知识库 `src/lib/catalog.json`（505 项，`scripts/build-catalog.mjs` 由 Claude 按十个阶段穷举，含孕期 58 项和妈妈自己的用品）：每项 id（跨阶段稳定）、中英名、类别（14 类含 mom、gear、sleep、safety、outings）、层级、月龄范围、每月/一次性/偶尔、自有品牌价、用量、省钱办法、母乳/奶粉适用、是否必需。`src/lib/catalog.ts` 按月龄和喂养方式筛选；偶尔项按 /3 折成每月；一次性项单独算，勾了「已有」（`state.owned`）就不算。
- 每月开销模型 `src/lib/stages.ts`：按实际月龄分十段（含孕期，出生年月填未来即预产期）（0–2、3–5、6–8、9–11 个月、1 岁、1 岁半、2 岁、3–4 岁、5 岁+），每段列出尿布、湿巾、奶/牛奶、辅食/饭、衣服换码、玩具启蒙、书、健康、护理，和第三层「开心与出游」。每项带美国自有品牌保守价和省钱办法（图书馆、WIC、Buy Nothing、Museums for All）。按三层汇总，总基线喂给 Pal。
- 库存 `src/lib/inventory.ts`：尿布、奶粉（按冲好的 ml 计）、湿巾三样。通过 Pal 付款时，判定项里的 `supply_type / supply_qty` 自动加进库存；按档案里的每日消耗推算今天还剩多少、还能用几天。≤7 天算「快见底」：欢迎卡里出黄色提醒，快捷提问里出现「帮我买尿布」，首页有库存卡。「我 → 库存」可以手改数（在别处买了）。
- 宝宝头像：默认用通义万相出的软陶风格婴儿头像（`public/baby.png`，候选在 `docs/baby-candidates`），「我 → 编辑」可上传真照片（存为 data URL 在状态里）。首页 Pal 立绘旁边有宝宝头像。
- 成长时间轴 `src/components/BabyTimeline.tsx`：按 stages 的九段画轨道，当前段按月龄进度点亮，列出本段「正在学」和下一段「接下来」的典型里程碑（`MILESTONES`，CDC 式范围，不是诊断）。
- 换月自动归档：日历翻页或点「重置本月」，本月判定与账单整体存入 `history`。

### 月度管家（Month run，第二轮的核心，2026-10-11）
- 首页欢迎卡第一个按钮「Plan the rest of the month / 帮我排好这个月剩下的」。给 Pal 一个目标（用剩下的钱让宝宝这个月什么都不缺），它分步自己做完，每一步做完就存档（`state.runs`），断了从下一步接着做；失败的那一步有「从这一步重试」。
- 五步（`src/lib/month-run.ts`）：① 盘点（不用模型：能花多少、留多少备用、还剩几天、三样消耗品撑到哪天、这个阶段的必需品、这个月已经买过什么、可能能领的福利）② 排计划（Claude 结构化输出：现在买 / 晚些买并给最晚日期 / 这个月不买；整包、自有品牌、马斯洛顺序、医疗备注优先、能领的先领；不许在文字里写金额）③ 查真实价格（Claude + 联网搜索，复用比价的 `findOffers`）④ 检查（不用模型：逐个打开链接，页面上看到这个价 / 能开 / 店家挡机器人 / 失效去掉；服务器重算钱；够不够用到月底；晚买日期在用完之前；必需品没够就不买成长和开心类；不重复买；文字里有金额就退回）⑤ 交购物车（一个普通 Plan，带 `run_id`、`later`、`checks`，PayPal 按钮照旧，妈妈自己确认付款）。
- 检查不过的处理：计划问题退回②重排（最多 2 次），没找到价格的只把那几样退回③再查一次；还解决不了的全部写进「请你看一眼」，不悄悄丢掉。
- 每一步记时间、token、搜索次数、估算花费；卡片底部写「这一次：X 秒，AI 花了 $Y」。
- 证据：`docs/evidence/`（三次真实运行的完整记录 + 从运行里发现的 5 个毛病和各自的修法）。

### 对话为主的布局（第二轮第 5 条，2026-10-12）
- 桌面：左侧栏（`src/components/Nav.tsx`）上半是 Pal（对话）和她自己管的工具（这个月 / 预算 / 能领的 / 我），下半是和 Pal 的对话历史 + 新对话，底部是当前家庭 + 切换。侧栏可收起成图标栏（记在本机）；右侧面板打开时默认收起，关掉面板恢复（`src/components/Sidebar.tsx`）。手机保留底部五个标签，顶栏有「对话」进列表（`/chat`）。
- 首页 = 一段对话（`src/app/page.tsx`）：上方简报（钱、省下的、库存最短天数、能领的，点了去对应工具页），下面是对话流，宽度收窄。Pal 的回答只有一两句 + 一张小卡；点卡片在右侧面板打开完整内容（判定卡 / 月度管家的步骤和购物车），手机上全屏。月度管家开始时桌面自动打开面板。地址 `/?c=<id>` 是哪段对话，`/?new=1` 是新对话。
- 对话存在 `state.conversations`（每段只记顺序和 plan/run 的 id），`/api/plan`、`/api/run` 带 `conversation_id`；老数据按每个判定/月度管家各算一段迁移过来。弹窗里问的也归到一段对话里。
- 月度管家拆成 `useRunDriver`（跟着对话走，关面板不停）和 `RunCard`（只显示）。
- 登录前页面（`/intro`）：首屏下加「Pal 自己能做的」三张卡，都是真实运行里的数字（Maya 那次检查拦下奶粉断档、德州 SNAP 官网原话找到、语音）；首屏直达三个演示家庭；示例里的真实家庭名字和皇后区数据换成虚构的 Leo / Maya；✓ 字符换成图标。

### 语音（第二轮第 4 条，2026-10-11）
- 首页、弹窗、对话页的输入框都有麦克风（`src/components/Voice.tsx`）：点一下说话，字边说边出现在框里，停顿 1.6 秒自动发出；用语音问的，Pal 把回答念出来（headline + note）。说或打「排好这个月 / plan the rest of the month」直接启动月度管家。
- 用浏览器自带的语音识别和朗读。Chrome 的识别走 Google 语音服务，音频会离开设备，对外文案照实说；我们自己不录、不存音频。不支持的浏览器（Firefox）不显示麦克风。界面中文就按中文识别和朗读。

### Pal cuts（它砍）
- 输入一段话 → Claude 结构化输出：每项 BUY / SWAP / SKIP / DEFER、平替名、价格、商家、理由、优先级、库存类型与数量。金额全部服务器重算，不信模型算术。
- 系统提示要点：饭钱锁死不能动；网红/品牌/小红书推荐一律可疑；健康安全第一且该看医生就说；按马斯洛分钱；库存够两周以上的消耗品判 defer；语气对物狠对人暖，短句，不惊叹。
- 全网比价（`/api/plan/[id]/compare`）：对未支付的判定，Claude 带联网搜索查 Walmart、Target、Amazon、Costco、Aldi、一元店、药房的真实报价（带链接），最便宜的排前面；比到更便宜就更新该项价格和商家，重算合计。Pal 不替任何一家店服务。
- PayPal Checkout（Orders v2）：按批准清单逐项建单，妈妈在 PayPal 弹窗确认，服务器 capture，账本记 capture id，预算条下降，库存入账。按钮下方显示沙盒买家邮箱和密码（各带复制按钮，读 `NEXT_PUBLIC_SANDBOX_BUYER_*`），换设备测试不用记；弹窗是 PayPal 的页面，无法代填。

### Pal claims（它领）
- 微调研 → PayPal Payouts v1 打到妈妈的沙盒个人账号，账本记 batch id，预算条上升。目前两张种子问卷。
- 出处核对（2026-10-11，第二轮第 2 条）：资源查询每项必须给官网页面 `source_url` 和逐字照抄的规定 `source_quote`；服务器打开页面找这句话（`src/lib/verify.ts`：原文找到 / 数字对得上 / 页面上没有 / 读不了，PDF 算读不了），标出处是不是政府网站（政府项目才要求官方，慈善和社区用自己的网站），逐个打开申请链接，失效的去掉。出处弱的（没给、页面上没有、政府项目却引第三方）退回一次，只许用官方页面再找。资源页每张卡有核对标记，展开能看官网原话和链接；顶部一行汇总 + 「把出处再核对一遍」（不调 AI，不花钱）。判定卡的「全网比价」也会逐个打开商品链接。
- 资源查询 `src/lib/resources-agent.ts`：按档案，Claude 带联网搜索查官方网站，列 8–12 个项目（WIC、SNAP 用州名、Medicaid/CHIP、尿布银行、Head Start、托育补贴、HEAP、Lifeline、学校餐、EITC/CTC、211、食物银行、免费物品群；有医疗备注再查 Early Intervention、儿童 SSI、WIC 医学奶粉）。每项：决定资格的那一条规则、每月值多少、三四步、要带的材料、官方链接电话、需核实的提醒。约两分钟。

### 账本
- 首页/预算页的简单账单列表 + 「看明细」→ 「我」里的 AG Grid 表：所有月份，排序、筛选、搜索、固定合计行、导出 CSV。标题「认真算账，认真生活」。AG Grid 只出现在这一处（为 Best Use of AG Grid 奖）。

## 技术

- Next.js 16 App Router + Tailwind 4 + TypeScript。字体 Inter + Noto Sans SC / 苹方。配色 Ant Design 中性灰底 + 标准蓝 #1677ff；红只给「砍」，绿只给「钱回来」。
- AI：`@anthropic-ai/sdk`，模型 `claude-opus-5`。判定用 `messages.parse` + Zod；资源查询和比价用 `messages.stream` + `web_search_20260209` + 结构化输出（max_tokens 32k，effort medium），资源查询有两步兜底。
- PayPal：`src/lib/paypal.ts` 直连沙盒 REST（Orders v2 create/capture，Payouts v1；注意 Payouts 的金额字段是 `currency` 不是 `currency_code`）。前端 PayPal JS SDK 按钮。
- 状态：单用户一份 JSON。配了 Supabase 就存 `app_state` 表的一行（`STATE_ROW_ID` 选哪一行；本地 `.env.local` 设成 `dev`，线上演示是 `default`，本地测试不碰线上数据）（Vercel 多实例必须每次读表，不走内存缓存）；否则 `data/state.json`。
- 登录：`/api/login` 写 `mp_session` + `mp_row` 两个 cookie，`src/middleware.ts` 没 cookie 的页面请求跳 `/intro`。每个家庭一行状态：演示码（MAYA-DEMO / ROSA-DEMO / KEISHA-DEMO，`src/lib/personas.ts`）给访客复制一份私有副本（行名 `maya-xxxxxx`），互不影响；用名字登录是一个新的空家庭，先走五步引导。没有 `mp_row` 的老 cookie 落到 `STATE_ROW_ID` 或 `default`。不是真正的认证。三个演示家庭都是虚构的（休斯顿喝奶粉的 4 个月宝宝、哥伦布孕期 + 2 岁、弗雷斯诺牛奶过敏的 10 个月 + 4 岁），地点和项目是真的；提前算好的福利报告放在 `src/data/personas/*.json`，副本直接带上。「我」页顶部提示「你在 X 家演示数据的副本里 · 换一个家庭」。
- 形象：通义万相 `wan2.2-t2i-plus` 出图，`scripts/cutout.mjs` 去白底成透明立绘。原图在 `docs/pal-candidates`、`docs/pal-poses`，立绘在 `public/pal-*.png`。
- 部署：GitHub `main` 自动部署到 Vercel。环境变量：ANTHROPIC_API_KEY、PAYPAL_CLIENT_ID、PAYPAL_CLIENT_SECRET、NEXT_PUBLIC_PAYPAL_CLIENT_ID、PAYOUT_RECEIVER_EMAIL、SUPABASE_URL、SUPABASE_SERVICE_ROLE_KEY。

## 边界（对外要说清楚）

- 仅沙盒，不在真实商店下单；商家名是建议，比价链接是搜索当天的结果。
- 价格是估算或当天搜索价，不是实时报价。
- 库存只记三样，别处买的要手改。
- 资源结果是 AI 查官网整理，每张卡都提醒向项目方确认；不是法律或福利咨询，不是医疗建议。
